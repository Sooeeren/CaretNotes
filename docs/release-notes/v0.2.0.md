### Downloads
- **Windows:** `CaretNotes-Setup-0.2.0.exe` installs CaretNotes for you (no admin rights needed) and keeps it up to date.
  Prefer no install? `CaretNotes-0.2.0-portable.exe` is one file you just run.
  Windows SmartScreen may warn because the files aren't signed. Choose **More info**, then **Run anyway**.
- **Linux:**
  - Debian, Ubuntu, Mint, Pop!_OS: `caretnotes_0.2.0_amd64.deb`
  - Fedora, openSUSE, RHEL: `caretnotes-0.2.0-1.x86_64.rpm`
  - Arch, Manjaro, EndeavourOS: `caretnotes-0.2.0-1-x86_64.pkg.tar.zst` (`sudo pacman -U` it)
  - Any other distro: `CaretNotes-0.2.0-x86_64.AppImage` (make it executable and run it; it updates itself)
- **Android:** `CaretNotes-0.2.0.apk` (early preview). Allow installing from unknown sources, then open the file.

**New version numbers:** earlier releases were renamed from 1.0.0–1.3.0 to 0.1.0–0.1.3, because CaretNotes is still young. If you have 1.3.0 installed, it won't offer this update by itself: download and install 0.2.0 once, and updates work as before from then on. Your notes are not touched.

### What's new
- **Quick colors in the toolbar:** your most recent pen colors sit right in the tool pill, with a palette button next to them for any color (color wheel, brightness and hex code). **Settings → Pen & touch** sets how many show (3 by default, or none).
- **Pen panel with a preview:** tap the pen again to see how a stroke will look with the chosen type, size and color. Colors come in pages you flip through with the arrows.
- **Move the toolbar by its grip** (the dots at its start) and drop it at the top, bottom, left or right edge. Holding it anywhere still works too.
- **Full screen:** the new button in the top bar (or F11) hides everything but the page and the tools. Esc or the button in the corner brings it back.
- **Box select** is now the default selection; lasso is one tap away in the select tool's panel.
- **A proper eraser icon.**
- **Small windows:** the top bars make room (find, read mode and full screen move into the ⋮ menu; the search field folds into a button), you can drag the window by the note title, and there is always an empty strip of title bar to grab.

### Fixes
- Tapping the formatting bar (bold, list, …) while typing no longer ends typing and closes the bar.

Your notes stay where they were (`%APPDATA%\dev.caretnotes\caret_notes` on Windows, `~/.local/share/dev.caretnotes.caret_notes` on Linux).
