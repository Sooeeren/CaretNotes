### Downloads
- **Windows:** `CaretNotes-Setup-1.3.0.exe` installs CaretNotes for you (no admin rights needed) and keeps it up to date.
  Prefer no install? `CaretNotes-1.3.0-portable.exe` is one file you just run.
  Windows SmartScreen may warn because the files aren't signed. Choose **More info**, then **Run anyway**.
- **Linux:**
  - Debian, Ubuntu, Mint, Pop!_OS: `caretnotes_1.3.0_amd64.deb`
  - Fedora, openSUSE, RHEL: `caretnotes-1.3.0-1.x86_64.rpm`
  - Arch, Manjaro, EndeavourOS: `caretnotes-1.3.0-1-x86_64.pkg.tar.zst` (`sudo pacman -U` it)
  - Any other distro: `CaretNotes-1.3.0-x86_64.AppImage` (make it executable and run it; it updates itself)
- **Android:** `CaretNotes-1.3.0.apk` (early preview). Allow installing from unknown sources, then open the file.

### What's new
- **Its own icon:** an orange tile with a handwritten loop and a plum pen-tip dot. A sibling of CaretFlow's logo, not a copy.
- **Updates:** CaretNotes looks for a new version a few seconds after it starts and offers it, with the release notes. **Settings → Updates** has a *Check for updates* button and can turn the automatic check off. The Windows installer version and the AppImage update themselves (the download is checked against GitHub's SHA-256 first); the other versions open the right download.
- **Windows installer** and **Linux packages** for Debian/Ubuntu, Fedora/openSUSE, Arch and an AppImage for everything else.
- PDF export on Linux uses DejaVu or Liberation fonts.

Your notes stay where they were (`%APPDATA%\dev.caretnotes\caret_notes` on Windows, `~/.local/share/dev.caretnotes.caret_notes` on Linux).
