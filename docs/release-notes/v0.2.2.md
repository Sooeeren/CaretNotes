### Downloads
- **Windows:** `CaretNotes-Setup-0.2.2.exe` installs CaretNotes for you (no admin rights needed) and keeps it up to date.
  Prefer no install? `CaretNotes-0.2.2-portable.exe` is one file you just run.
  Windows SmartScreen may warn because the files aren't signed. Choose **More info**, then **Run anyway**.
- **Linux:**
  - Debian, Ubuntu, Mint, Pop!_OS: `caretnotes_0.2.2_amd64.deb`
  - Fedora, openSUSE, RHEL: `caretnotes-0.2.2-1.x86_64.rpm`
  - Arch, Manjaro, EndeavourOS: `caretnotes-0.2.2-1-x86_64.pkg.tar.zst` (`sudo pacman -U` it)
  - Any other distro: `CaretNotes-0.2.2-x86_64.AppImage` (make it executable and run it; it updates itself)
- **Android:** `CaretNotes-0.2.2.apk` (early preview). Allow installing from unknown sources, then open the file.

### What's new
- **Undo and redo in the toolbar:** they now sit in the toolbar with the pen and colors, so you can reach them in full screen too.
- **Grid paper by columns:** for grid paper, the slider now sets how many squares fit across the page (8–60), and the squares always fit the page exactly.
- **Your tools are remembered:** pen type, color and size, highlighter, eraser and selection settings carry over between notes and restarts.
- **Partial eraser by default:** the eraser removes only what it touches. Erasing whole strokes is still in the eraser's options.
- **Made with AI:** Settings has a new section at the bottom showing how many lines of CaretNotes' code were written with AI.

### Fixes
- **The S Pen button works:** hold it while writing to erase or select (choose which in Settings → *S Pen side button*). Before, the app ignored it.
- **The app is called CaretNotes everywhere:** Task Manager, the taskbar and the Android home screen showed "caret_notes".

Your notes stay where they were (`%APPDATA%\dev.caretnotes\caret_notes` on Windows, `~/.local/share/dev.caretnotes.caret_notes` on Linux).
