### Downloads
- **Windows:** `CaretNotes-Setup-0.2.1.exe` installs CaretNotes for you (no admin rights needed) and keeps it up to date.
  Prefer no install? `CaretNotes-0.2.1-portable.exe` is one file you just run.
  Windows SmartScreen may warn because the files aren't signed. Choose **More info**, then **Run anyway**.
- **Linux:**
  - Debian, Ubuntu, Mint, Pop!_OS: `caretnotes_0.2.1_amd64.deb`
  - Fedora, openSUSE, RHEL: `caretnotes-0.2.1-1.x86_64.rpm`
  - Arch, Manjaro, EndeavourOS: `caretnotes-0.2.1-1-x86_64.pkg.tar.zst` (`sudo pacman -U` it)
  - Any other distro: `CaretNotes-0.2.1-x86_64.AppImage` (make it executable and run it; it updates itself)
- **Android:** `CaretNotes-0.2.1.apk` (early preview). Allow installing from unknown sources, then open the file.

### What's new
- **Resize the ruler:** spread or pinch two fingers on it to make it longer or shorter (5–60 cm), while moving and turning it as before.
- **Change a quick color:** tap the color that's already chosen in the toolbar again to change it. The color wheel shows the old color next to the new one.
- **Plain lined paper:** lined paper without the red margin line (Paper → *Plain lined*).
- **Export preview:** the export dialog shows every page before you save.
- **No more handwriting cut in half:** when a long (endless) page or a canvas is split into A4 pages, each page now ends in a gap between lines of writing, leaving a bit of empty space at the bottom instead of slicing through your words.

### Fixes
- **Closing is instant:** CaretNotes used to stay on screen for several seconds after you closed it. It now closes right away.
- **Last edits are kept when closing with Alt+F4 or from the taskbar:** closing that way could lose what you wrote in the last second or two. Every way of closing now saves first.
- **"Check for updates" no longer fails with "GitHub answered 403".** GitHub limits how often a network may ask (which a school or university network reaches quickly); CaretNotes now falls back to a file attached to each release.
- **The eraser circle follows the pen** while you erase, not just while hovering.
- **The pen preview shows the difference between pen, fineliner and pencil:** it's drawn larger, so the pen's swell, the even fineliner and the lighter pencil are easy to tell apart.

Your notes stay where they were (`%APPDATA%\dev.caretnotes\caret_notes` on Windows, `~/.local/share/dev.caretnotes.caret_notes` on Linux).
