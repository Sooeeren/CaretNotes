# Keyboard shortcuts

| Keys | Action |
| --- | --- |
| Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) | Undo / redo |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste (also pastes images and text from other apps) |
| Ctrl+D | Duplicate selection |
| Delete / Backspace | Delete selection (while you type in a text, they edit the text) |
| Esc | Clear the selection |
| Ctrl+= / Ctrl+- / Ctrl+0 | Zoom in / out / fit width |
| Ctrl+mouse wheel | Zoom; wheel scrolls; Shift+wheel scrolls sideways |
| Ctrl+S | Save now (it also saves automatically) |
| Ctrl+F | Find typed text in the note (Enter / Shift+Enter: next / previous, Esc: close) |

## While typing text

| Keys | Action |
| --- | --- |
| Enter | New line (on lined paper: the next ruled line) |
| Ctrl+Z / Ctrl+Y | Undo / redo inside the text |
| Click outside | Finish typing (an empty text is removed) |

Markdown works as you type: `# heading`, `**bold**`, `*italic*`, `- list`, `- [ ] checkbox`, `` `code` ``, `$x^2$`. The bar above the text inserts the same.

Fingers scroll and pinch-zoom. Turn on **Draw with finger** if you have no pen. Hold the tool pill to drag it to the left or right side, or let it float anywhere.
